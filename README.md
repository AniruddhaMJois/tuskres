# 🐘 TUSKRES - Rescuing Tuskers 🛡️

**Team: THE POWER OF 5 A'S** 🚀


**TUSKRES** is a modern, high-tech early warning system designed to mitigate human-elephant conflict in sensitive zones. By providing real-time monitoring and rapid communication channels for forest officials and civilians, TUSKRES aims to create safer communities for both humans and elephants.

---

## 🚀 Features

- **🌑 Dual Theme Support**: Seamlessly switch between a high-contrast Dark Mode and a crisp Light Mode.
- **🌍 Multi-language Interface**: Full support for **English**, **Kannada (ಕನ್ನಡ)**, and **Hindi (हिन्दी)**.
- **📡 Real-time Monitoring**: Live thermal and RGB camera feeds from patrol zones.
- **🔊 Acoustic Alerts**: Scaled-up acoustic mic recordings to detect elephant movement through sound.
- **🚨 Rapid Warning System**: Secure mechanism for officials to broadcast instant warnings to specific zones.
- **🔐 Secure Authentication**: Role-based access for Forest Officers and Civilians with Supabase integration.
- **📱 Responsive Design**: A premium, app-like experience optimized for mobile and desktop use.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Modern UI), Vanilla JavaScript (ES6+).
- **Backend**: [Supabase](https://supabase.com/) for real-time database and authentication.
- **Assets**: Dynamic imagery and acoustic data integration for zone monitoring.

## 🏗️ Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/AniruddhaMJois/tuskres.git
   ```
2. **Setup Supabase**: Ensure you have your Supabase URL and Anon Key configured in `script.js`.
3. **Run Locally**: Simply open `index.html` in any modern web browser or use a local live server.
